# IEEE IES Industrial Innovation Conclave 2026

A complete Hugo-based conference website for the **IEEE IES Industrial
Innovation Conclave 2026 (I4C 2026)**.

The project combines the official conference content of I4C 2026 with a
reusable IEEE Industrial Electronics Society conference website architecture.

The website is built using **Hugo Extended 0.141.0** and the
**Hugo Relearn theme**, maintained as a Git submodule.

The project uses project-level Hugo layouts, partials, shortcodes, CSS,
configuration, content, static assets, SEO files, and GitHub Actions to create
and deploy the conference website.
