# `static/css/custom.css` — Custom Styles

- **File**: [`static/css/custom.css`](../../static/css/custom.css)
- **Loaded by**: [`layouts/partials/custom-header.html`](../../layouts/partials/custom-header.html)
- **Risk on Relearn upgrade**: 🟡 **MEDIUM** — several rules target Relearn internal selectors that may change between theme versions.

The custom stylesheet provides surgical visual overrides for the I4C 2026 website. It does not contain global resets or broad theme replacements.

If a Relearn selector changes during an upgrade, the affected element normally falls back to the theme's default styling rather than causing a build failure.

---

## What each rule block does

| Selector / Prefix | Purpose |
|---|---|
| `#R-topbar`, `#R-topbar .topbar-wrapper` | Adds the topbar shadow and controls its minimum height. |
| `#R-topbar .topbar-breadcrumbs` | Styles the breadcrumb/page title using IEEE blue and responsive typography. |
| `#R-topbar .site-brand-logos` | Controls the IEEE IES and IEEE logos displayed in the topbar. |
| `#R-topbar .site-brand-logos img` | Controls the size and scaling of the topbar logos. |
| `#R-sidebar #R-header-wrapper` | Adjusts spacing around the sidebar header/logo area. |
| `#R-logo.R-default img.site-logo` | Controls the main sidebar logo size and display. |
| `#R-logo.R-default .logo-title` | Styles the site title displayed below the sidebar logo. |
| `#R-sidebar ul.collapsible-menu > li` | Tightens the vertical spacing between sidebar menu items. |
| `#R-sidebar ul.collapsible-menu > li > input/label` | Aligns the sidebar collapse controls with the menu links. |
| `#R-sidebar ul.page-toc-menu` | Styles the H1-based page TOC items generated by the custom menu partial. |
| `#R-sidebar .menu-footer-class` | Centers the IEEE IES and IEEE logos displayed at the bottom of the sidebar. |
| `#R-sidebar #R-homelinks` | Removes the unused Relearn home-header background. |
| `#R-sidebar ul.collapsible-menu > li.active.parent` | Gives an active parent section a bordered/highlighted container. |
| `main#R-body-inner article p` | Justifies article paragraphs. |
